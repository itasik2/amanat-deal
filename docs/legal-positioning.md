# Legal positioning v0.1

## Роль платформы

Amanat Deal предоставляет цифровой сервис фиксации условий сделки, статусов, уведомлений и доказательной базы.

Платформа не должна позиционироваться как:

- банк;
- платёжная организация;
- страховая организация;
- букмекер/тотализатор;
- суд;
- арбитраж по умолчанию.

## Споры

Базовая платформа не разрешает спор по существу. При проблеме она:

1. останавливает автоматическое завершение;
2. фиксирует заявление и доказательства;
3. даёт сторонам возможность добровольно договориться;
4. сохраняет пакет событий и файлов для суда, медиации или арбитража, если стороны отдельно выбрали такой путь.

## Деньги

В пилоте реальные деньги не принимаются. На следующем этапе денежный поток должен идти через банк/платёжного партнёра, а платформа должна получать только свою комиссию за цифровую услугу.
