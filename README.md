# Amanat Deal

Пилотный проект платформы безопасных сделок: продавец создаёт сделку, покупатель принимает условия и оплачивает через mock-escrow, продавец отправляет товар, после подтверждения получения или истечения срока проверки сделка завершается.

## Принцип MVP

- API/backend является ядром продукта.
- Web/PWA, admin и будущие мобильные клиенты работают только через API.
- Реальные деньги в MVP не подключены: используется `mock-escrow`.
- Платформа не выступает арбитром. Она фиксирует условия, события и доказательства.

## Стек

- Monorepo: npm workspaces
- Web/PWA: Next.js + TypeScript
- Admin: Next.js + TypeScript
- API: NestJS + TypeScript
- Database: PostgreSQL + Prisma
- Queue: Redis/BullMQ, позже
- Files: S3/R2-compatible storage, позже

## Быстрый старт

```bash
npm install
cp .env.example .env
npm run prisma:generate
npm run dev
```

## Основные сценарии пилота

1. Продавец создаёт сделку.
2. Покупатель принимает условия по ссылке.
3. Mock-escrow переводит сделку в статус `FUNDS_SECURED`.
4. Продавец указывает доставку и трек-номер.
5. Покупатель подтверждает получение или истекает срок проверки.
6. Mock-escrow завершает сделку.
7. Если сообщена проблема, автоматическая выплата останавливается, платформа сохраняет доказательную базу.
